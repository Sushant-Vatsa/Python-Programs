# Python Programs

This repository contains a collection of basic to intermediate Python programs that I created while learning the language. The scripts cover a wide range of concepts, from simple logic building to pattern printing and mathematical problems.

## 📚 Topics Covered

- Conditional statements and loops  
- Functions and user input  
- Pattern printing  
- Mathematical problems (e.g., Armstrong numbers, factorials, prime numbers)  
- String manipulation  
- List and array operations  
- Number theory basics

## 🛠️ Purpose

These programs were written as part of my learning journey in Python. The goal was to strengthen my logical thinking, get comfortable with Python syntax, and build a strong foundation before diving into Data Structures, Algorithms, and real-world applications like web development and AI/ML.
